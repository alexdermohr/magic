Manabrew-Account verbinden

Verbinde deinen bisherigen Account über GitHub oder Discord. Die Anmeldung findet direkt beim jeweiligen Anbieter statt. Manabrew zeigt danach einen einmaligen Anmeldecode an.

Für E-Mail-Anmeldung kannst du direkt im normalen Manabrew-Anmeldedialog den Code aus der Mail eingeben. Deinen Account oder dein Passwort musst du hier nicht angeben. Der Code wird von der originalen Manabrew-Anwendung verarbeitet.
