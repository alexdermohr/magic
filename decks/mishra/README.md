# Mishra, Eminent One

## Ziel

Ein starkes **Bracket-3-Artefaktdeck**, das Mishras besondere Stärke ausnutzt: vorhandene Nichtkreatur-Artefakte werden im Kampf temporär als Warforms instanziiert.

Das Deck soll abwechslungsreich und modular spielen, aber bewusst nicht in cEDH, frühe Zwei-Karten-Infinite-Combos oder Extra-Turn-Ketten kippen.
