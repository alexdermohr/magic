Ian erzeugt beim gemeinsamen Kartenziehen einen Pool fremder Zauber. Wheels, Draw-/Discard-Schaden und wenige klare Finisher sorgen dafür, dass das Deck auch ohne die optimale Nutzung gegnerischer Karten gewinnen kann.

**Drei Game Changer:** Ancient Tomb, Fierce Guardianship, Cyclonic Rift. Keine frühen Zwei-Karten-Infinite-Combos oder Extra-Turn-Ketten. Für 1v1 ausdrücklich ein Spaß-/Experimentdeck, kein Ruxa-Ersatz.
